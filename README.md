# 🛒 E-Commerce Android App

A modern **E-Commerce Android application** built with **Kotlin and Jetpack Compose**, featuring Firebase Authentication, product sharing, smooth animations, API integration, and a clean shopping experience.

## ✨ Features

* 🏠 Modern and responsive Home screen
* 🔍 Product search
* 🛍️ Browse products
* 📄 Product details
* 🔗 Share products with other apps
* ❤️ Wishlist functionality
* 🛒 Add and manage products in Cart
* 👤 User Profile
* 🔐 Firebase Authentication
* 🎨 Modern and improved UI
* ✨ Smooth Jetpack Compose animations
* 🔄 MVVM-based state management
* 💾 Local data persistence
* 📱 Responsive UI for different screen sizes


## 🔐 Authentication

Firebase Authentication is integrated to provide user authentication.

Users can:

* Create an account
* Login securely
* Logout
* Manage their authenticated session

## 🎨 UI & Animations

The app uses **Jetpack Compose** with **Material 3** to create a modern user interface.

UI improvements include:

* Smooth screen transitions
* Animated UI elements
* Responsive layouts
* Modern cards and components
* Interactive buttons
* Clean product presentation
* Improved user experience
